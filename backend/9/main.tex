\indheader{06}{DIGITAL TWIN INTERFACE}

\textbf{INTERFACE GUIDE: TWIN MANAGER v5.0}
\par
The Digital Twin interface provides a real-time, browser-based supervision of the factory floor. It is built using \textbf{React.js} and \textbf{Three.js} to render a 3D interactive scene alongside critical live data.

\vspace{0.5cm}

\section*{\faDesktop\ 1. 3D VISUALIZATION (CANVAS)}
The Dashboard features a \texttt{ComplexFactoryScene} that renders the physical layout:
\begin{itemize}
    \item \textbf{Assets:} Displays CNC Machines, Robot Arms, and Conveyor Belts.
    \item \textbf{Status Indicators:} Machines change color dynamically based on their health state: 
    \textcolor{BrandSuccess}{\textbf{Green (Running)}}, \textcolor{BrandWarning}{\textbf{Amber (Idle)}}, or \textcolor{BrandDanger}{\textbf{Red (Warning)}}.
    \item \textbf{Animation:} Robot arms and AGVs (Automated Guided Vehicles) move in sync with the production cycle time.
\end{itemize}

\vspace{0.5cm}

\section*{\faChartLine\ 2. PREDICTIVE MAINTENANCE (SCATTER CHART)}
The Maintenance module utilizes a \textbf{Risk Matrix Scatter Chart} to correlate three key variables:
\begin{itemize}
    \item \textbf{X-Axis:} Temperature (°C).
    \item \textbf{Y-Axis:} Machine Health (\%).
    \item \textbf{Z-Axis (Point Size):} Vibration levels.
\end{itemize}
\textbf{Logic:} The system triggers a \texttt{status="warning"} if Temperature > 90°C. This allows operators to visualize outliers (machines that are hot and vibrating) before failure occurs.

\vspace{0.5cm}

\section*{\faCalculator\ 3. TCO OPTIMIZATION (BAR CHART)}
The \textbf{Total Cost of Ownership (TCO)} calculator projects financial data over 10 years based on live telemetry.
\begin{itemize}
    \item \textbf{Calculation:} \texttt{Total = CAPEX + (Power * Hours * Cost) + Maintenance}.
    \item \textbf{Stacked Bar Chart:} Visualizes the accumulation of OPEX (Energy + Maintenance) on top of the initial CAPEX investment.
    \item \textbf{User Inputs:} Financial directors can adjust Energy Cost (€/kWh) and Years to simulate different ROI scenarios.
\end{itemize}

\vspace{0.5cm}

\section*{\faShieldAlt\ 4. SAFETY \& ATEX MONITORING}
For hazardous zones (e.g., Painting Robot), the system monitors air quality.
\begin{itemize}
    \item \textbf{Data Viz:} An Area Chart tracks PPM (Parts Per Million) of VOCs/Solvents in real-time.
    \item \textbf{Automation:} If concentration spikes, ventilation status switches to "100\%" instantly.
\end{itemize}
